## Seams S2 provides

```ts
// apps/marketplace/src/deal/index.ts  (S2-owned; Esha's gateway imports it)
reviewDeal(deal_id: string): Promise<DealCard>                 // review_deal → structuredContent, view "deal-card"
payApprovedDeal(deal_id: string, credential?, ctx?: { buyer?, run_id? }): Promise<PayResult>   // pay_deal
dealSummary(card: DealCard): string                            // text for the model
createDealModule({ deals, catalog, payDeal?, logEvent? })      // Bridge 1: pass E1's exchange + S1's catalog
```

- **Payment:** E1 validates first, then S2 charges the stored amount through `@sa/payments` and logs `payment_succeeded` or `payment_failed`. There is at most one charge per deal, even if a retry uses a different card.
- **Refusals:** returned as normal results with `status: "refused"`, a `reason` and a `fix`. They are not `isError`, so the card can show them.
