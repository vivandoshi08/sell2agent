**Policies:**
- `static`: list price, final. The baseline.
- `negotiating` (current default): holds list in round 1, t⁴, at most 75% of the gap. From E10.
- `balanced`: t³ to the soft floor. From E5/E10.
- `lever_policy`: gated off.

**Guarantees, in code:**
- Never below the soft floor (hard floor + 3% of the gap) + the cost of included extras.
- Never accepts below the hard floor, never raises a price it already offered, never charges above list.
- `final` only on the last round.
- `voice()` rejects any dollar figure that isn't the offer, the list price or an earlier price. It also rejects floor/cost talk, a false "final", and any extra not in the offer. One retry, then a safe template.

**Buyer harness:**
- 5 lever-profile personas. Each has a stated budget below a private walk-away; the walk-away is a hard cap in code.
- About 10% red-team buyers (injected `SYSTEM:` line, fake competitor quote, floor probing).
- Brains: `claude` / `gpt` / `scripted`.
- Commands: `pnpm buyers --exchange --n 30 --models claude` (static vs negotiating vs balanced through E1's exchange), or `--gateway https://dark-zero-mesv5.run.mcp-use.com/mcp` for S1's deployed gateway. A gateway outage shows as `ERROR gateway: …`.

**Events** (`runs/*.events.jsonl`, plus Supabase `events` when `SUPABASE_URL` is set). Every harness event carries:
- `payload.policy`
- `payload.buyer_persona` (`adversarial` for red team)
- `payload.lever_profile`

Seller offer events add `lever_package` and `expires_at`. `deal_accepted` adds `deal_id`, `lever_package`, `list_price_cents`. The wallet guard logs `guardrail_blocked` with `payload.rule = "buyer_wallet_cap"`.
