PR #90 security finding (fix before turning Inkbox on): a stranger can accept someone else's live offer by email and get its approve link. The Inkbox signature proves Inkbox delivered the webhook, not who wrote the email (Inkbox's message.received payload carries no SPF/DKIM result). The door routes by any off_… in the text and then acts as that offer's buyer; from_matches_consent is only logged. Offer ids sit in events.payload.offer_id for every counter, and events is readable with the public anon key. Reproduced in a scratch test on main + #90: the victim negotiates over MCP (no walk-away, no follow-up consent); the attacker reads the offer id from events and sends a signed email from their own address with ACCEPT off_… → state agreed, an approve link signed for the victim is mailed to the attacker. The seller still gets at least the floor; the attacker buys at the victim's price and the victim's deal is gone. Not exploitable on production today (no INKBOX_SIGNING_KEY; plain JSON needs OUTREACH_SECRET). Fix: for Inkbox mail, route only to a negotiation with follow-up consent whose followup.reply_to equals normalizeAddress(from), else treat it as unrouted; add that test. Left after the fix: a forged From of the victim's own address can still lock the deal, but the link goes to the victim and nothing is charged.

Other #90 checks: verifyInkboxSignature matches Inkbox's spec exactly (X-Inkbox-Request-ID/Timestamp/Signature, unix seconds, HMAC-SHA256 over {request_id}.{timestamp}.{raw}, sha256= hex, 300 s window), compared in constant time. Replays inside the window are deduped by the signed event id (two identical requests at the same instant could both run; the second accept fails). Cron, outbox and plain-JSON routes refuse when OUTREACH_SECRET is unset. Nits: GET /outbox also takes ?key=, which lands in request logs (header only); unrouted mail gets one auto-reply per address per day with no global cap (backscatter to forged addresses). Env on Manufact: OUTREACH_SECRET (required), FOLLOWUP_DELAY_MS=60000 for the demo, and OUTREACH_TICK_MS=15000 or a cron on /cron/outreach: the Dockerfile sets NODE_ENV=production, so the timer is off by default. Leave INKBOX_* unset until the fix lands.
